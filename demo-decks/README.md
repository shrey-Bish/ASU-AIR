# Demo decks

The two decks the demo runs on, committed so the team can pull them without
passing files around. Both are **real ASU course material**.

| File | Course | Why this one |
|---|---|---|
| `asu-intro-machine-learning.pptx` | ASU — Introduction to Machine Learning | The primary demo. Slide 13's existing alt text is a Windows file path; the review queue fills to 11 of 23 images. ~50s to run. |
| `asu-phy111-chapter2-part1.pptx` | ASU PHY 111 — physics | The secondary demo. Not computer science, 23 of 23 described, and 7 images carry useless figure-code alt text (`0202a`, `0203`). ~45s to run. |

See [NEXT_STEPS.md](../NEXT_STEPS.md) for what to show in each.
